# ToDo

A simple and functional Todo List application built using HTML, CSS, and Vanilla JavaScript.

This project allows users to manage daily tasks efficiently by adding, editing, completing, and deleting todos. All data is stored in the browser's LocalStorage, ensuring persistence even after page reload.

---

## Features

- Add new tasks
- Edit existing tasks inline
- Mark tasks as completed/uncompleted
- Delete all tasks
- Persistent data storage using LocalStorage
- Keyboard support (press Enter to add task)

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- LocalStorage API
- DOM Manipulation
